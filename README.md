# 技能库 · 状态补给

个人技能变现库 + 状态补给站。**知道我会什么、能卖多少钱；闲着的时候，该干什么。**

🔗 在线访问：https://noahsusu.github.io/skill-vault/

## 五个模块

| 模块 | 干什么 |
|---|---|
| **技能库** | 13 项技能，每项挂：怎么用、变现路径 + 市场参考价、收益预估、下一步具体动作 |
| **变现地图** | 三档生意模型（卖时间 / 卖产品 / 卖认知）+ 接单收入计算器 |
| **状态补给** | 29 个动作，按「精力 × 场景 × 类别」筛选后随机抽签，打卡记录 |
| **学习队列** | 未完成的课程 + 进度条+ 为什么必须看完 + 今天这一步 |
| **收益追踪** | 近6 个月柱状图，按技能聚合真实收入 |

## 手机上怎么装

**iOS Safari**：分享 → 添加到主屏幕
**Android Chrome**：菜单 → 安装应用 / 添加到主屏幕

装完可以离线打开，没网也能用。

## 跨设备同步

数据默认存在浏览器本地（localStorage），**不跨设备**。两种同步方式：

1. **📱 同步到手机**（快）：点底部「📱 同步到手机」→ 生成一条带数据的链接 → 用手机打开那个链接 → 确认导入。适合小改动。
2. **导出文件**（大改动）：底部「导出文件」存JSON，手机上「导入」选它。

⚠️ 同步链接会把数据放在 URL 里，别发到公开的地方。

## 技术说明

- 纯静态，零依赖，单页运行（`index.html` 约 60 KB）
- 数据存localStorage，不上传任何服务器
- PWA：`sw.js`（网络优先缓存）+ `manifest.webmanifest`
- 图标：`icon.svg` 为源文件，PNG 由 Chrome headless 渲染
